🎓 CollegeIQ — Complete Project Steps
🚀 Overview
This is the codebase for CollegeIQ, a next-generation college discovery platform designed to help students make confident and informed decisions.


🛠️ Running the Project

Follow these simple steps to run the project locally:

📦 Install Dependencies
npm install
▶️ Start Development Server
npm run dev
🌐 Live Deployment

You can deploy this project easily using platforms like Render.
